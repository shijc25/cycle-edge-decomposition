# Release downloads

This branch stores the checked distribution files for *An explicit bound of twelve for cycle-edge decompositions* by Jiacheng Shi.

The complete Lean sources, manuscript, verification records, and reproduction instructions are on the [main branch](https://github.com/shijc25/cycle-edge-decomposition/tree/main).

Version 1.0.0 is dated November 6, 2026. The files under `v1.0.0/` are byte-identical to the checked publication edition. `SHA256SUMS` lists the checksums of the complete source ZIP, paper source ZIP, and paper PDF.
